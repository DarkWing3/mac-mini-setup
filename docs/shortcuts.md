# Mac 단축키 모음

[← 홈으로](index.md)

## 시스템 단축키

| 단축키 | 동작 |
|--------|------|
| `⌘ Space` | Spotlight 검색 |
| `⌘ Tab` | 실행 중인 앱 간 전환 |
| `⌘ \` | 같은 앱 내 다른 창으로 전환 |
| `⌘ Q` | 현재 앱 완전히 종료 |
| `⌘ W` | 현재 창 또는 탭 닫기 |
| `⌘ H` | 현재 앱 창 숨기기 |
| `⌘ M` | 현재 창 Dock으로 최소화 |
| `⌃ ⌘ Q` | 화면 잠금 |
| `⌘ ⇧ 3` | 전체 화면 캡처 |
| `⌘ ⇧ 4` | 선택 영역 캡처 |
| `⌘ ⇧ 5` | 화면 캡처 및 화면 기록 도구 열기 |

## Finder 단축키

| 단축키 | 동작 |
|--------|------|
| `⌘ N` | 새 Finder 창 열기 |
| `⌘ ⇧ N` | 새 폴더 생성 |
| `⌘ Delete` | 선택 항목 휴지통으로 이동 |
| `⌘ ⇧ Delete` | 휴지통 비우기 |
| `⌘ I` | 파일/폴더 정보 가져오기 |
| `Space` | 훑어보기 (Quick Look 미리보기) |
| `⌘ ⇧ .` | 숨김 파일 표시/숨김 토글 |

## 터미널 단축키

| 단축키 | 동작 |
|--------|------|
| `⌃ C` | 현재 실행 중인 프로세스 강제 종료 |
| `⌃ L` | 화면 지우기 (Clear) |
| `⌃ A` | 커서를 줄의 맨 앞으로 이동 |
| `⌃ E` | 커서를 줄의 맨 뒤로 이동 |
| `⌃ R` | 이전 명령어 히스토리 역방향 검색 |

## 텍스트 편집 단축키

| 단축키 | 동작 |
|--------|------|
| `⌘ A` | 전체 텍스트 선택 |
| `⌘ Z` | 실행 취소 (Undo) |
| `⌘ ⇧ Z` | 다시 실행 (Redo) |
| `⌥ →` / `⌥ ←` | 단어 단위로 커서 이동 |
| `⌘ →` / `⌘ ←` | 줄의 맨 뒤/맨 앞으로 커서 이동 |
| `fn Delete` | 커서 뒤의 글자 삭제 (Forward Delete) |
